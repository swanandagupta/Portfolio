```text
User / Mobile Application
├── Authentication Module
├── Safe Route Planner
├── Guardian Mode

        ↓

        ↓
Risk Intelligence Engine

        ↓
AI Risk Prediction Model & Route Optimization
├── Safest Path Selection
├── Fastest Path Selection
└── Balanced Hybrid Route
        ↓
Application Backend & Firebase Store
├── Users & Emergency Logs
├── Live Journey Stream
└── Guardian Alert Notification Pipeline
```
